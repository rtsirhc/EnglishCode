# 🎓 EnglishCode

All of Christine's interactive English (ESL) classroom games, apps and activities in one place.

> Every folder is a separate game. **Easy games** open by double-clicking `index.html`. **App games** need Node.js: run `npm install` and then `npm run dev` (or `npm start` if it has a server) inside the folder.
